# Physics Quiz

A local-first progressive web app for taking multiple-choice physics quizzes from shareable question bank files, and for keeping a local history of results.

This file is the project glossary. It records what words mean here, not how anything is built.

## Language

### Authoring

**Question Bank**:
A single self-describing file, authored by a teacher or generated by an AI assistant, holding a set of questions plus the metadata that identifies it. Short form "bank" is fine.
_Avoid_: Quiz file, question set, deck, test

**Bank Author**:
The person or tool that produced a bank. Never a user of the app in that role.
_Avoid_: Creator, owner

**Bank ID**:
The stable identifier a bank declares for itself, unchanged across editions of that bank.
_Avoid_: Bank name, slug

**Bank Version**:
The edition of a bank, declared by its author and bumped when the questions change. Distinct from the app's own version.

**Bank Fingerprint**:
The hash of a bank file's exact bytes, used to tell two files apart when their author gave them the same Bank ID and Bank Version.
_Avoid_: Checksum, digest, ETag

**Question**:
One prompt with a fixed set of options, exactly one of which is correct.

**Option**:
One selectable answer belonging to a question.
_Avoid_: Choice, alternative, answer (an option is not "the answer" unless it is the correct one)

**Distractor**:
An option that is not the correct one. A term of art from assessment design, used when talking about question quality.

**Explanation**:
The author's justification of the correct answer, shown only in review. The main thing that makes the app pedagogic rather than merely a scoreboard.
_Avoid_: Feedback, solution, rationale

### Taking a quiz

**Library**:
The set of banks held in this browser, and the app's home screen. A bank enters the library by upload or by URL and stays there for offline use.
_Avoid_: Collection, catalogue, my banks

**Participant**:
The person taking an attempt, identified by nothing more than the name they type at the start. Two attempts with the same name are assumed to be the same person, and the app never asserts more than that.
_Avoid_: User, player, student, account

**Attempt**:
One sitting: a named person answering a selection of questions drawn from one bank, from start to submission. The unit that history, export and the leaderboard are all made of.
_Avoid_: Quiz run, session, game, play, try

**Attempt Code**:
The short human-readable string identifying one attempt, meant to be read aloud, typed, or pasted. This is the "unique short ID".
_Avoid_: Attempt number, receipt, reference

**Selection**:
The N questions drawn from the bank for one attempt, in the order they will be presented.
_Avoid_: Question set, sample, batch

**Review**:
The screen shown after submission, listing every question in the attempt with the participant's choice, the correct option and the explanation. There is no feedback before it.
_Avoid_: Results, summary, report card

**History**:
Every attempt held in this browser, newest first, and the place where export and import live. Spans all banks.
_Avoid_: Log, records, past quizzes

**Leaderboard**:
A ranking of the attempts held in this browser for one bank. It ranks attempts, not people, and it never spans banks, because scores on different banks are not comparable.
_Avoid_: Scoreboard, rankings, high scores

**Share Link**:
A link carrying one attempt inside its URL fragment, so a participant can hand a result to someone else without a server. The receiving browser recomputes the score rather than believing it.
_Avoid_: Result link, share code (the Attempt Code is a different thing)

**Unverified**:
The status of any attempt that arrived by import or share link rather than being taken in this browser. The app cannot prove such an attempt is genuine and says so rather than implying otherwise.
_Avoid_: Untrusted, external, foreign
